# Godofredo Alves — Portfolio

A concise, recruiter-focused portfolio for Godofredo Alves, a Toronto-based software architect and engineering leader.

## Stack

- PHP 8.3
- Modern CSS
- Vanilla JavaScript

## Run locally

```bash
php -S localhost:8080
```

Then open `http://localhost:8080`.

## Structure

- `index.php` — page structure and presentation content
- `data.php` — structured career and profile information
- `assets/css/styles.css` — responsive visual design
- `assets/js/main.js` — navigation and disclosure interactions
- `assets/images/` — portrait and supporting image assets
